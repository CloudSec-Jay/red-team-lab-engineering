# Web application labs

## Source-backed starting point

The archived authentication notes document response-based username enumeration as completed study material and identify three review dimensions: uniform status codes, generic error messages, and consistent response timing. No screenshots, raw traffic, timestamps, or target record were migrated, so this project treats it as `source-notes`, not an executed lab.

## Planned sequence

1. Authentication response consistency on a deliberately vulnerable local application.
2. Input-handling validation with application and reverse-proxy telemetry enabled.
3. Access-control testing with two isolated test identities.
4. File-handling and server-side request boundary reviews.

Each run must use the repository lab template and produce sanitized evidence before its status can become `executed`.
