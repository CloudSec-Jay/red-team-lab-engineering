02

Execution system

The lab does not begin
with a payload.

  1. 01

    Authorize

    Record ownership, scope, time window, exclusions, stop conditions, and recovery.

  2. 02

    Hypothesize

    Name the control under test and the telemetry expected when it succeeds or fails.

  3. 03

    Exercise

    Use the minimum bounded action required inside an isolated target.

  4. 04

    Preserve

    Sanitize requests, responses, logs, timestamps, and teardown confirmation.

  5. 05

    Hand off

    Send observable behavior and detection gaps to the SecOps project without duplicating rule ownership.
