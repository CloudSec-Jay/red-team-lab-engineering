# Sanitized evidence

Do not commit raw credentials, session tokens, cookies, private keys, customer data, unrestricted packet captures, or unsanitized scanner exports.

An executed lab should include a manifest derived from `templates/evidence-manifest.example.json` and sanitized artifacts sufficient to support the result. Artifact filenames should include the lab ID and an ISO-style timestamp. Evidence must preserve timezone information and record teardown completion.

This directory contains no execution evidence yet.
